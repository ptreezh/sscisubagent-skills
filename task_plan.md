# Planning-with-Files Integration for Social Science Analysis Skills

## Goals
1. Implement the planning-with-files methodology (task_plan.md, findings.md, progress.md) for each individual analysis skill
2. Create independent workflow structures for grounded theory, ANT, and field analysis skills
3. Maintain persistent documentation for each skill's multi-step analytical process
4. Ensure transparent and reproducible analysis workflows
5. Preserve the autonomy of each analytical approach while maintaining consistent documentation standards

## Steps

### Phase 1: Grounded Theory Skill Integration
1.1. Create dedicated task_plan.md for grounded-theory-expert skill
1.2. Create dedicated findings.md for grounded-theory-expert skill  
1.3. Create dedicated progress.md for grounded-theory-expert skill
1.4. Map the five-phase workflow (open, axial, selective coding, saturation, memo writing) to planning-with-files structure
1.5. Ensure all grounded theory coding stages are properly tracked

### Phase 2: ANT Skill Integration  
2.1. Create dedicated task_plan.md for ant skill
2.2. Create dedicated findings.md for ant skill
2.3. Create dedicated progress.md for ant skill
2.4. Map the six-phase workflow (actor mapping, network analysis, translation tracking, material-semiotic analysis, dynamics assessment, synthesis) to planning-with-files structure
2.5. Ensure all ANT analysis phases are properly tracked

### Phase 3: Field Analysis Skill Integration
3.1. Create dedicated task_plan.md for field-analysis skill
3.2. Create dedicated findings.md for field-analysis skill
3.3. Create dedicated progress.md for field-analysis skill
3.4. Map the seven-phase workflow (field identification, mapping, capital analysis, power relations, autonomy assessment, habitus understanding, synthesis) to planning-with-files structure
3.5. Ensure all field analysis phases are properly tracked

### Phase 4: Quality Assurance
4.1. Verify each skill has independent planning-with-files structure
4.2. Confirm all multi-step workflows are properly represented
4.3. Test documentation persistence for each skill
4.4. Validate that skills maintain autonomy while following consistent standards

### Phase 5: Documentation
5.1. Document the integrated structure in main files
5.2. Provide guidelines for using the integrated system
5.3. Create references for maintaining the system
5.4. Archive the implementation for reproducibility

## Resources Needed
- Access to all three skill directories (grounded-theory-expert, ant, field-analysis)
- Understanding of each skill's multi-step workflow
- Consistent markdown templating capability
- File system access for creating triad structures per skill
