# SSCI (Social Science Computational Intelligence) Integration Skill

This skill provides access to 50+ specialized research skills for social science research, integrated with planning persistence.

## Available Skills

### Grounded Theory Expert
- `skill grounded-theory-expert [params]` - Perform grounded theory analysis
- Functions: Open coding, axial coding, selective coding, theory saturation

### Network Computation
- `skill network-computation [params]` - Perform network analysis
- Functions: Centrality analysis, community detection, visualization

### Field Analysis
- `skill field-analysis [params]` - Perform Bourdieu field analysis
- Functions: Boundary identification, capital analysis, habitus analysis

### Actor-Network Theory (ANT)
- `skill ant [params]` - Perform ANT analysis
- Functions: Actor identification, translation process analysis

### Digital Marxist Analysis
- `skill digital-marx [params]` - Perform digital marxist analysis
- Functions: Historical materialist analysis, alienation analysis

### Fuzzy-set QCA Analysis
- `skill fsqca-analysis [params]` - Perform fsQCA analysis
- Functions: Calibration, truth table analysis, solution identification

### Business Ecosystem Analysis
- `skill business-ecosystem-analysis [params]` - Perform ecosystem analysis
- Functions: Actor mapping, relationship analysis, value flow analysis

## Integration with Planning

All SSCI skills integrate with the planning-with-files system to:
- Maintain research continuity across sessions
- Preserve important findings and insights
- Track progress in research projects
- Prevent goal drift during analysis
